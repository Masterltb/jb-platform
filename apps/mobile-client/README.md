# Mobile Client (PWA / Mobile Wrapper)

> Thư mục dành cho việc đóng gói bản Mobile (PWA / Capacitor / Webview) cho tựa game **Anhem JaeBin – Ăn Chơi Điệu Nghệ**.

## 📌 Định hướng:
- Game chính được phát triển chạy trực tiếp trên nền tảng **Web (Next.js / React)** tại `apps/web-portal/`.
- Người dùng di động có thể chơi trực tiếp qua trình duyệt web điện thoại hoặc cài đặt qua tính năng **PWA (Add to Home Screen)**.
- Giai đoạn phát hành mở rộng: Đóng gói Web app bằng **Capacitor** hoặc **Unity Webview Wrapper** để xuất bản lên Google Play Store và Apple App Store.
