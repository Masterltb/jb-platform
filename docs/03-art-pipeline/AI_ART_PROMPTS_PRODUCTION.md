## 1. Nguyên Tắc Vàng (The Ironclad Art Rules)

Để tránh lỗi hiển thị đè sao hoặc dính chữ tiếng Hàn/Anh vào ảnh như phiên bản ban đầu:
1. ❌ **CẤM TUYỆT ĐỐI**: Các từ khóa như `card frame`, `ui`, `hud`, `stars`, `text`, `border`, `rating`, `korean text`, `game card template`.
2. ✅ **BẮT BUỘC DÙNG NEGATIVE PROMPT CHUẨN**:
   ```
   --no text, letters, watermark, signature, trademark, typography, korean letters, chinese characters, stars, ranking badges, card borders, card frame, ui, hud, user interface, status bar, numbers
   ```
3. 🎨 **TỈ LỆ KHUNG HÌNH (ASPECT RATIOS)**:
   - Thẻ nhân vật / Avatar: `--ar 3:4` hoặc `--ar 1:1`
   - Vũ khí / Trang bị / Vật phẩm: `--ar 1:1`
   - Boss hoành tráng / Minh họa trận đấu: `--ar 16:9` hoặc `--ar 4:3`
   - Shortclip Cutscene / Chiêu Thức: `--ar 16:9`
